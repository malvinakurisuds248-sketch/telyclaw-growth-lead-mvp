# TelyClaw Growth Lead — MVP Demo

> 从公开信号到内容分发的 AI 增长工作台。

线上 Demo：<https://telyclaw-growth-lead-demo.malvinakurisuds248.chatgpt.site/>

## 1. 产品概览

TelyClaw 面向出海 B2B / SaaS 增长团队。它不把“高浏览量”直接等同于“值得跟进”，而是帮助操盘者判断一个话题是否具备：足够快的讨论势能、可信的独立信源、与产品的关联度，以及可转化的受众意图。

本 MVP 展示以下闭环：

```text
监听账号 / 自定义关键词
        ↓
热点雷达：筛选、排序、解释机会指数
        ↓
内容工坊：选择内容策略并编辑草稿
        ↓
人工审核：驳回、重新构思、确认排期
```

## 2. 已实现能力

### 热点雷达

- 内置 AI 与科技、游戏、财经、股票、跨境电商、新能源等垂直信号流；
- 支持用户输入自定义关键词，并按 `15 分钟 / 1 小时 / 每日` 切换观察窗口；
- 热点卡片按机会指数从高到低排列；
- 每个热点展示讨论增速、独立信源数、时效信息和五维评分依据；
- 为当前热点推荐值得加入监听的高权重账号。

### 监听信源管理

- 默认提供 5 个监听账号；
- 支持从精选信源包批量添加、粘贴多行账号、录入 X List URL；
- 支持查看和移除已监听账号；
- 推荐账号可一键加入监听队列。

### 内容工坊与人工审核

- 每个热点提供 3 个内容角度：`独家锐评`、`深度拆解`、`场景切入`；
- 提供可编辑的单条 Post 草稿与 280 字进度提示；
- 展示对应的信源佐证链；
- 支持驳回原因、重新构思、人工确认和模拟排期分发。

### AI 与数据适配层

- DeepSeek 在服务端承担趋势解释和机会判断；
- 已实现 X Recent Search 适配：按关键词和时间窗口拉取公开 Posts、提取作者与互动指标，再交给 TelyClaw 分析；
- API 密钥仅放在部署环境变量中，绝不写入前端页面或 Git 仓库；
- 对公开扫描增加了每 IP 15 分钟 8 次的基础限流。

## 3. 热点识别与排序逻辑

### 机会指数（Opportunity Score）

TelyClaw 使用五维过滤，而不是只看点赞量：

| 维度 | 关注的问题 | 业务意义 |
| --- | --- | --- |
| 讨论加速度 | 讨论是在爆发还是衰退？ | 尽量在早期爬坡阶段介入 |
| 信源质量 | 是否由多个可靠账号独立发声？ | 区分行业共识和单点噪音 |
| 产品相关度 | 能否自然连接到产品工作流？ | 避免“热点很大但不转化” |
| 商业意图 | 评论与讨论中是否出现真实问题？ | 寻找高意向受众 |
| 时效窗口 | 话题是否仍处于可介入周期？ | 降低追逐过期热点的概率 |

排序时优先考虑：趋势速度、独立作者数、互动质量、产品相关度和新鲜度。页面会同步展示分数依据，确保操作者能理解“为什么它排在前面”。

## 4. 内容生成逻辑

对于选中的热点，系统先将“热点结论 + 可验证信号”转换为三种打法：

1. **独家锐评**：提出可辩论的反直觉判断，吸引高质量讨论；
2. **深度拆解**：解释变化为何发生、影响谁、团队可以如何行动；
3. **场景切入**：从真实决策摩擦切入，再连接到产品价值。

草稿始终保留人工编辑和审核节点。MVP 不自动代表用户发帖；“确认并排期分发”目前是安全的模拟发布动作。

## 5. 系统架构

```text
Browser UI (app/index.html)
        │  POST /api/ai/analyze
        ▼
Cloudflare Worker (dist/server/index.js)
        ├── X Recent Search：拉取公开 Posts、作者与互动指标
        └── DeepSeek：基于真实信号给出趋势判断
        ▼
返回：机会指数、摘要、原帖证据、推荐监听账号
```

核心源文件：

```text
app/index.html             # 单页交互界面
scripts/build-worker.mjs   # Worker 构建脚本、X 与 AI 服务逻辑
dist/server/index.js       # 构建产物，不建议手动编辑
.openai/hosting.json       # 托管项目配置
```

## 6. 本地构建

本项目不依赖 npm 安装；修改源页面后运行：

```powershell
node scripts/build-worker.mjs
```

这会从 `app/index.html` 生成 Cloudflare Worker 入口 `dist/server/index.js`。

部署环境需要配置以下服务端密钥：

```text
DEEPSEEK_API_KEY   # 用于趋势分析
X_BEARER_TOKEN     # 用于读取公开 X Posts
```

不要将任何 Token 写入 `.js`、`.html`、README 或提交到仓库。

## 9. 3–5 分钟演示建议

1. 打开“热点雷达”，说明机会指数为何不等于浏览量；
2. 输入一个关键词，切换时间窗口，展示排序与五维依据；
3. 查看推荐监听账号，并加入一个账号；
4. 选择“独家锐评 / 深度拆解 / 场景切入”之一，进入内容工坊；
5. 修改草稿，进入审核与分发，完成模拟排期；
6. 说明生产环境中由 X API 提供实时证据、由 DeepSeek 做分析、由人工完成最后发布确认。
